# The 2018 Intel Mac mini is the v1 show machine

v1 must run the show on the 2018 Intel Mac mini (Intel UHD 630). The composition is authored at home on an Apple Silicon laptop, transferred to the Mini, and the Mini runs the gig on its own. The laptop is a company machine and does not go to gigs.

So the engine ships as a Universal binary, and the performance budget is set by the UHD 630, not by Apple Silicon. Apple Silicon measurements (M2 Pro: typical comp ~5.8 ms GPU per frame) only serve as an upper reference. Resolume Arena already ran 2 outputs on this Mini.
